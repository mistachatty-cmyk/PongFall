## What PongFall is
Pong in a constantly falling arena. Each side is behind glass that breaks after 3 missed balls (no repair); after a break, a ball through the hologram goal line is an auto-score. Walls have eyes (metal lids): one hit opens them all and drops a tear. Scoring grows your arena (slows the fall); the opponent scoring shrinks it. Ends on target score, time, or the arena wedging against both walls. Planned: Kinetic Souls-style creative sandbox, playable as a mini-game inside other games, LOK sign-in, LokTokens, leaderboards.

## Gotchas
- **Never use the word "signal"** anywhere (CLAUDE.md rule).
- Any change that alters how a recorded run plays out must bump `SIM_VERSION`; `replay.test.ts` guards determinism. Render-only state must never feed the sim.
- Test script quoting matters: `"test": "tsx --test \"src/**/*.test.ts\""`.
- Clones here are shallow/single-branch; if a git hook says "no remote branch", fetch with `+refs/heads/<b>:refs/remotes/origin/<b>`.
- Do not `pkill -f` a pattern that appears in your own command line (it kills the shell).
- Sibling game: `mistachatty-cmyk/Kinetic-Souls` (4k-line single file, mock LOK passport); borrow ideas (modifiers, unlimited mode, themes), not structure. Full plan lives in the session plan and `CLAUDE.md`'s milestone list.

## 0.8.0 tilt, arm rework, keys, music (SIM_VERSION 10)
- Paddle tilt: `tilt` command, `Side.ta`; only bends the return angle (collision stays axis-aligned, tilt 0 is byte-identical to before). Atan lives in `sim/detmath.ts`.
- Pinball arm: `Side.grow` 0..1 grows out only while `powerActive`; no host carry-over (`createPongFall` no longer passes `host.isPowerUnlocked`; sandbox still starts armed). Player 2 has no arm (power is NPC-only for side 1).
- Keys: `core/controls.ts` (bindings, swap-on-rebind, reserved keys) + `controlsPanel.ts`, C toggles it. Stored in settings `keys`.
